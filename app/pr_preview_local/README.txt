FastAPI PR Review — 로컬 테스트

이 패키지는 PR 코드 구조도, 저장소 현재 구조·목적별 검토 계획·구조 개선 후보 비교를 포함한 개발본입니다.
기존 공개 사이트에 새 버전이 배포되었다는 뜻은 아닙니다.

실행 준비: Python 3.10 이상, 최신 웹 브라우저, GitHub에 접속할 인터넷 연결.
Pyodide 분석 런타임은 패키지에 포함됩니다. OpenAI API와 API 키는 사용하지 않습니다.

1. ZIP 전체를 압축 해제합니다. index.html을 직접 열지 마세요.
   직접 열기 안내가 나오면 ‘웹서비스에서 열기’로 이동하거나 아래 실행 방법을 사용하세요.
   이전 화면의 PR·범위가 주소에 남아 있다면 복구 링크가 알려진 분석 설정만 이어줍니다.
2. macOS: START.command를 엽니다.
   실행 권한 때문에 열리지 않으면 터미널에서 이 폴더로 이동해 python3 start.py를 실행합니다.
   Windows: 이 폴더에서 py -3 start.py를 실행합니다.
   Linux: 이 폴더에서 python3 start.py를 실행합니다.
3. 브라우저가 열리지 않으면 터미널에 표시된 http://127.0.0.1:포트/ 주소를 엽니다.
4. PR 비교: ‘FastAPI 예제로 시작’을 누르거나 공개 PR 주소를 입력해 ‘변경 확인’을 누릅니다.
   ‘PR 관련 코드 구조’에서 이전/이후 전환, 코드 근거 링크, SVG 저장을 확인합니다.
   API/DB 관점, 경로, 모델 클래스를 바꾸어 본인의 PR로도 확인할 수 있습니다.
5. 현재 구조: ‘저장소 현재 구조’에서 ‘저장소 예제로 시작’을 누릅니다.
   본인의 공개 저장소 URL, 40자리 커밋 SHA, Python 소스 루트도 지정할 수 있습니다.
   파일과 참조 방향을 선택하면 import 근거, 라우트·테이블 선언과 선택 구조 SVG를 확인합니다.
   사용 목적을 온보딩·변경 검토·테스트 계획으로 바꾸어 확인 순서와 다음 행동을 살펴보세요.
   ‘검토 계획 복사’로 커밋·범위·코드 근거와 한도를 함께 복사할 수 있습니다.
   ‘구조 비교 예제’는 SQLModel 공식 저장소의 고정 커밋을 읽습니다.
   근거가 있는 파일의 ‘구조 개선 후보 비교’에서 현재와 미적용 가정·변경할 관계·전제·검증·단점을 확인합니다.
   비교 SVG 저장과 읽기 전용 비교 텍스트를 제공합니다. 제안 역할은 실제 새 파일이 아닙니다.
6. 종료할 때 터미널에서 Ctrl+C를 누릅니다.

고정된 포트가 필요하면: python3 start.py --port 8766
브라우저 자동 열기 없이 실행하려면: python3 start.py --no-browser

서버는 이 컴퓨터의 127.0.0.1에만 연결됩니다. 외부 기기에 공개되지 않습니다.
브라우저가 GitHub의 공개 PR·소스를 직접 조회하므로 비인증 API 한도가 적용됩니다.
대상 코드를 실행하지 않습니다. PR 모드는 변경 파일의 직접 선언을 비교합니다.
저장소 모드는 지정한 소스 루트의 Python 최대 100개·파일당64KiB를 읽습니다.
모듈 경로가 유일한 직접 import만 연결하며 파일80개·관계400개까지 표시합니다.
조건부·동적 import, 패키지 재수출, 소스 루트 밖의 관계는 미확인으로 남습니다.
지원 언어·파일 한도 밖의 전체 구조, 호출 관계, 실제 운영 인프라, 마이그레이션 실행 결과는 확인하지 않습니다.
목적별 계획은 관찰한 선언에 따른 검토 제안이며 실제 테스트 실행이나 개선 설계 검증 결과가 아닙니다.
구조 개선 후보는 라우트·테이블 공존 또는 직접 import 순환의 일부만 비교합니다.
후보가 없다는 이유로 구조가 적절하거나 개선이 불필요하다고 판단하지 않습니다. 코드는 자동 수정하지 않습니다.
